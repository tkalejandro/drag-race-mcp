# Drag Race MCP (WIP!!!) 👑

> An unofficial, community-driven MCP (Model Context Protocol) server for Drag Race knowledge.

`drag-race-mcp` provides AI assistants with structured information about Drag Race queens, seasons, challenges, winners, eliminations, and more through the Model Context Protocol (MCP).

This project is built for the community and welcomes contributions from fans and developers alike.

> **Disclaimer**
>
> This is an **unofficial fan project** and is **not affiliated with, endorsed by, or sponsored by** RuPaul, World of Wonder, or the Drag Race franchise.

## ✨ Features

- 👑 Search queens
- 📺 Retrieve season information
- 🏆 List winners and finalists
- 🎭 Episode and challenge information
- ⚖️ Compare queens
- 📚 Community-maintained knowledge base
- 🤖 MCP-compatible with AI clients

## 🛠 Planned MCP Tools

| Tool | Description |
|------|-------------|
| `search_queens` | Search queens by name or nickname |
| `get_queen` | Retrieve detailed information about a queen |
| `get_season` | Get season information |
| `get_episode` | Retrieve episode details |
| `list_winners` | List winners by franchise or season |
| `compare_queens` | Compare two or more queens |
| `recommend_season` | Recommend seasons based on preferences |
| `search_lore` | Search fan lore and historical context |
